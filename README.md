**🧠 Image Classification Using Traditional ML Algorithms**

**📘 Project Overview**

This project focuses on image classification using traditional supervised machine learning algorithms—specifically Support Vector Machine (SVM) and K-Nearest Neighbors (KNN). 
You'll work with the Fashion MNIST dataset, which contains grayscale images of clothing items (like shirts, sneakers, and bags).

The goal is to:

*Preprocess the dataset

*Engineer useful features

*Train and evaluate ML models (SVM and KNN)

*Compare their performance

**🛠️ What You’ll Learn**

How to load and explore the Fashion MNIST dataset

Data preprocessing techniques for image classification

Implementing SVM and KNN classifiers with Scikit-learn

Evaluating model performance using accuracy, confusion matrix, and classification report

Comparing traditional ML models

**📂 File Structure**

APPLICATIONS_OF_SUPERVISED_LEARNING.ipynb

Main Jupyter Notebook where all the code, comments, and analysis are written.

*▶️ How to Run*

Make sure you have Python 3.7+ installed.

Install required libraries using pip:pip install numpy pandas matplotlib seaborn scikit-learn

Open the notebook:jupyter notebook APPLICATIONS_OF_SUPERVISED_LEARNING.ipynb

Run each cell step-by-step to follow along the ML workflow.

**📊 Dataset Used**

Fashion MNIST

70,000 grayscale images of fashion items

10 classes (T-shirt/top, Trouser, Pullover, Dress, etc.)
28x28 pixel images
You fetch it using fetch_openml() from sklearn.datasets.

**📈 Models Implemented**

Support Vector Machine (SVM)

K-Nearest Neighbors (KNN)

Both models are evaluated and compared using accuracy and visual metrics.
